# Security policy

## Supported versions

Only the current release of TTM Connect from the Chrome Web Store, Edge Add-ons and Firefox Add-ons (AMO) gets security fixes.

## Reporting a vulnerability

Please report it privately, and don't open a public issue for it. Either way works:

- **On GitHub** (needs a GitHub account): on this repository's **Security** tab, choose **Report a vulnerability**.
- **By e-mail** (no account needed): write to [contact@kmarflow.com](mailto:contact@kmarflow.com?subject=TTM%20Connect%3A%20security%20vulnerability&body=Please%20do%20NOT%20file%20this%20as%20a%20public%20issue.%0D%0A%0D%0AExtension%20version%3A%0D%0ABrowser%20and%20version%3A%0D%0AWhat%20is%20affected%3A%0D%0AHow%20to%20reproduce%20it%20%28step%20by%20step%29%3A%0D%0AImpact%3A%0D%0A) with the subject "TTM Connect: security vulnerability".

Please include the extension version, the browser, what is affected and how to reproduce it. A fix ships as an update to each store, and the advisory is published once the update is out.
